## 🔍 KitLens

**KitLens** is a developer tool for analyzing React/design-system component usage across your codebase. It scans projects, identifies component usage, and generates structured reports to help developers understand and track their UI architecture.

🛠️ **Built with:** React · TypeScript · Vite · Node.js

📦 **NPM:** [kitlens](https://www.npmjs.com/package/kitlens)
🌐 **GitHub:** [github.com/okrahul/kitlens](https://github.com/okrahul/kitlens)

> 🚀 Built to make design-system usage easier to understand, analyze, and improve.
